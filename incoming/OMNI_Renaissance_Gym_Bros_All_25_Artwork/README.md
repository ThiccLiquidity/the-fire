# Renaissance Gym Bros — approved set

Theme: Renaissance Gym Bros. Art: richly coloured Renaissance fresco.
Characters: Frog, Mushroom, Praying Mantis, Rooster, Sloth.
Approved masters: revised varied-background images.

Each folder contains original_wood_gold.png (unchanged original shared by Wood and Gold), paper.png, fire.png, coal.png, and full_art.png.
