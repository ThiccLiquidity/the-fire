# OMNI — Jean Phil × Painted Cubism

Characters: Lobster, Pigeon, Toaster, Cactus, Jellyfish.

Each character folder contains five PNGs:
- original_wood_gold.png: unchanged full-colour master, shared by Wood and Gold.
- paper.png: pencil/graphite treatment.
- fire.png: active flame treatment.
- coal.png: matte black charcoal treatment.
- full_art.png: proportional crop of the original at 1500 × 2100, rounded exterior with outer edge and both panel outlines.

No baked-in holo, gold overlays or wear. Material edits generated directly from each original using image generation. Full-art uses deterministic scaling, cropping, masking and outline compositing.
